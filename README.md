# Johnny-Upgrade-Poptracker
This is a Poptracker to show where every coin and whats in logic and might be possible not the actual mod

The actual mod and the creator is https://github.com/barretg/johnny-upgrade-ap

To install the poptracker 
1. download the zip from release
2. get poptracker if you dont have already https://github.com/black-sliver/PopTracker/
3. open the poptracker folder and place the zip file in the packs folder
